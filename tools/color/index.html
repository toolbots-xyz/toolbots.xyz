How it works

      
Enter a HEX value or use the picker. The tool converts between HEX, RGB, and HSL, computes WCAG 2.1 relative-luminance
      contrast ratios against white and black, and derives a 9-swatch palette (4 tints, the base color, 4 shades).

      
Privacy

      
All math runs locally — no network requests at all on this page.
