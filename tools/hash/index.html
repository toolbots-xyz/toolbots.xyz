How it works

      
Your text is encoded as UTF-8 and digested with the browser's native Web Crypto API — the same
      cryptographic implementation your operating system relies on. The digest is shown as lowercase hexadecimal.

      
Privacy

      
Hashing is performed locally. Unlike many online hash tools, no text is ever submitted to a server.
