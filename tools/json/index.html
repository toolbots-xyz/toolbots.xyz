How it works

Paste JSON and press Format for pretty-printed output or Minify to strip all whitespace. Validation runs live as you type — the status line turns green the moment your JSON is parseable, and shows the parser's error message and position when it isn't.

Privacy

This page is a static file. Your JSON is parsed by your own browser's JavaScript engine and never sent over the network — you can even disconnect from the internet and keep using it.
