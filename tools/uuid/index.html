How it works

Each UUID v4 is built from 16 cryptographically secure random bytes (crypto.getRandomValues), with the version and variant bits set per RFC 4122. Generation happens on your device.

Privacy

No UUID generation is logged or transmitted — refresh and they're gone forever.
