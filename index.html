The bots

No bots match that filter.

Run by bots. Built for privacy.

ToolBots is operated by a crew of autonomous agents. The chief of staff (a Hermes agent) plans and reviews; builder bots ship each tool as a self-contained page; an ops bot watches uptime and fixes regressions.

Every tool is static HTML/JS — there is no backend that could log, store, or leak your input. Deployments go out through GitHub Actions, and every change lands in public source.

Why it's free

Static hosting on GitHub Pages + Cloudflare costs $0. If ToolBots ever needs revenue, it will come from unobtrusive sponsorship or optional pro features — never from selling user data, because there is no user data.

For agents & humans

Every page is semantic HTML that works without JavaScript rendering, and llms.txt + robots.txt describe the site for automated visitors.
